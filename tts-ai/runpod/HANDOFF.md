# 📬 คู่มือใช้เซิร์ฟเวอร์เสียงประจำช่อง — สำหรับ Claude แชทอื่น/โปรเจกต์อื่น

> ถ้าคุณคือ Claude ที่ถูกส่งมาอ่านไฟล์นี้: นี่คือระบบเสียงพากย์ของช่อง ใช้เจนเสียงพูดภาษาไทยสำหรับคลิป
> เจ้าของช่องจะให้ **URL** และ **API key** มาในแชท — สองอย่างนี้ไม่อยู่ใน repo (ห้าม commit ลง repo เด็ดขาด)

## ระบบนี้คืออะไร

- เซิร์ฟเวอร์ TTS บน RunPod GPU: โมเดล **OmniVoice-Thai** (ไฟน์จูนไทย, Apache-2.0) + เสียงโคลนประจำช่อง (จาก `tts-ai/tests/ref/`)
- **แปลงตัวเลขอัตโนมัติในตัว** — ส่งข้อความดิบมีเลข "18:30 น. / 2,500,000" ได้เลย เซิร์ฟเวอร์อ่านเป็นคำไทยให้เอง (`normalize_th.py`)
- เจ้าของช่องเปิด pod เฉพาะเวลาใช้ — **ก่อนสั่งงานให้เช็ค `/health` ก่อนเสมอ** ถ้าไม่ตอบ = pod ปิดอยู่ ให้แจ้งเจ้าของช่องเปิด (URL เดิมใช้ต่อได้หลังเปิด)

## Endpoints

Base URL รูปแบบ: `https://<POD_ID>-8000.proxy.runpod.net`

| Method | Path | Auth | ใช้ทำอะไร |
|---|---|---|---|
| GET | `/health` | header `x-api-key` | เช็คสถานะ + เวอร์ชันเสียง (`ref` บอกว่าใช้เสียงจริงหรือเสียงชั่วคราว) |
| GET | `/say?key=..&text=..` | query `key` | เจนประโยคเดียว เล่นได้ในเบราว์เซอร์ (เหมาะให้มนุษย์ลองฟัง) |
| GET | `/listen?key=..` | query `key` | ฟังเสียงล่าสุดซ้ำ |
| POST | `/tts` body `{"text":"..."}` | header `x-api-key` | ได้ไฟล์ wav (header `x-seconds` = ความยาววินาที) |
| POST | `/job` body `{"job":"ชื่อ","segments":[{"id":"s01","text":"..."}]}` | header `x-api-key` | ได้ไฟล์ **zip**: wav ทุก segment + `timing.json` |

## วิธีสั่งเสียงทั้งคลิป (ทางมาตรฐาน)

**1. สร้างไฟล์งาน** `tts-ai/voice-jobs/<ชื่อคลิป>.json` ใน repo แล้ว commit (เผื่อรันซ้ำ/ตรวจย้อนหลัง):

```json
{
  "job": "2026-08-ชื่อคลิป",
  "segments": [
    {"id": "s01_hook", "text": "อะไรนะครับ! ยอดวิวพุ่งไป 2,500,000 วิวในคืนเดียว"},
    {"id": "s02_setup", "text": "เรื่องมันเริ่มตอน 18:30 น. ของวันธรรมดาวันหนึ่ง"}
  ]
}
```

กติกาเขียน `text`: เว้นวรรค = จังหวะหยุดหายใจ / คำอังกฤษเขียนได้แต่ถ้าอ่านเพี้ยนให้เปลี่ยนเป็นทับศัพท์ไทย ("YouTube" → "ยูทูบ") / ตัวเลขปล่อยดิบได้เลย เซิร์ฟเวอร์แปลงเอง

**2. ยิงงาน** — เลือกทางใดทางหนึ่ง:

```bash
# ทาง A: สคริปต์สำเร็จรูป (ต้องมี python + requests; แตก zip ให้เสร็จ)
python tts-ai/runpod/client.py --server <URL> --key <KEY> \
  --job tts-ai/voice-jobs/<ชื่อ>.json --outdir <โฟลเดอร์ปลายทาง>

# ทาง B: curl ตรง ๆ
curl -X POST -H "x-api-key: <KEY>" -H "Content-Type: application/json" \
  --data-binary @tts-ai/voice-jobs/<ชื่อ>.json <URL>/job -o voice.zip
```

**3. ผลลัพธ์** — โฟลเดอร์/zip ประกอบด้วย `<id>.wav` ทุก segment (24kHz mono) + `timing.json`:

```json
[{"id": "s01_hook", "file": "s01_hook.wav", "seconds": 4.87, "chars": 42,
  "text": "ข้อความต้นฉบับ", "gen_text": "ข้อความหลังแปลงตัวเลข"}]
```

ใช้ `seconds` วางไทม์ไลน์ตัดต่อ (CapCut) ได้ทันที — segment ไหนเจนพลาดจะมี `"error"` แทน `"file"` (ตัวอื่นยังมาครบ)

## ข้อผิดพลาดที่พบบ่อย

| อาการ | ความหมาย | ทำยังไง |
|---|---|---|
| ต่อไม่ติด / timeout | pod ปิดอยู่ | แจ้งเจ้าของช่องเปิด pod (Start → วางคำสั่งใน README นี้ → รอ ✅ ~5 นาที) |
| 401 `x-api-key ไม่ถูกต้อง` | key ผิด/ไม่ได้ส่ง | ขอ key จากเจ้าของช่อง (อาจเปลี่ยนเมื่อรีสตาร์ท) |
| 500 `เจนเสียงล้มเหลว: ...` | ปัญหาฝั่งเซิร์ฟเวอร์ | ส่งข้อความ error ทั้งก้อนให้เจ้าของช่อง/แชทหลัก |
| `/health` ตอบ `"ref": "เปรมวดีชั่วคราว..."` | ยังไม่ได้ติดตั้งเสียงจริง | ใช้ได้ แต่เสียงยังไม่ใช่เสียงประจำช่อง |

## กติกาสำคัญ

1. **ห้าม commit API key / URL ลง repo** — รับจากเจ้าของช่องทางแชทเท่านั้น
2. เสียงโคลนเป็นเสียงส่วนตัวของเจ้าของช่อง — ใช้เฉพาะงานคลิปของช่องนี้
3. งานเสร็จแล้วเตือนเจ้าของช่อง **กด Stop pod** เพื่อหยุดค่าใช้จ่าย
4. อยากรู้ลึกกว่านี้: `tts-ai/runpod/README.md` (การตั้ง pod), `tts-ai/README.md` (ภาพรวมระบบเสียง)
