# weird-stories — คลิปเล่าเรื่องประหลาด คดีแปลก จากทั่วโลก

pipeline ทำคลิปสารคดีสั้นแบบ **ภาพนิ่ง + Ken Burns + เสียงบรรยายไทย** ตั้งแต่ต้นจนได้ mp4
ใช้ Gemini API ทั้งหมด (TTS / ภาพ / ดนตรี) และ ffmpeg ประกอบ — **รันจบได้ในเซสชันนี้ ไม่ต้องพึ่ง PC**

> โปรเจกต์นี้แยกจาก `projects/2026-07-*` (Story Remix) ที่ต้องใช้ CapCut + ElevenLabs บนเครื่อง PC
> ตัวนี้ออกไฟล์ mp4 สำเร็จรูปเลย

---

> **ค่าใช้จ่าย API:** อ่าน `COST.md` ก่อนเริ่มทำตอนใหม่
> สรุปสั้น: **เสียงฟรี** (วิ่งไปที่ key free tier เอง) · **ภาพลด 50%** (Batch API) ·
> **ของเดิมไม่จ่ายซ้ำ** (แคช content-addressed)

## เริ่มยังไง

```bash
cd projects/weird-stories

# 0. เพิ่ม/เปลี่ยน key เมื่อไหร่ รันตัวนี้ก่อน เพื่อให้ระบบเลือก key ให้ตรงงาน
python3 tools/check_keys.py

# 1. เขียนสคริปต์ + shotlist ของตอนใหม่
mkdir -p episodes/ep01-ghost-blimp
# สร้าง script.json และ shots.json (ดูตัวอย่างใน episodes/ep00-demo-dancing-plague/)

# 2. gen เสียง -> audio/*.wav + audio/timing.json
python3 tools/gen_voice.py episodes/ep01-ghost-blimp/script.json

# 3. gen ภาพ -> images/*.jpg   (ใช้ Batch API ราคาครึ่งเดียว รอคิวราว 10-15 นาที)
python3 tools/gen_images.py episodes/ep01-ghost-blimp/shots.json
#    ถ้าต้องการผลทันทีและยอมจ่ายเต็ม: เติม --now

# 4. gen ดนตรีประกอบ -> audio/bgm.mp3   (ข้ามได้)
python3 tools/gen_music.py episodes/ep01-ghost-blimp "dark ambient drone, tense, no vocals"

# 5. ประกอบเป็นคลิป -> output.mp4
python3 tools/build_video.py episodes/ep01-ghost-blimp
python3 tools/build_video.py episodes/ep01-ghost-blimp --vertical   # เวอร์ชัน Shorts
```

ทุกสเตปเป็น **incremental** — gen แล้วข้ามของเดิม ถ้าอยากแก้เฉพาะบางท่อน/บางช็อต ใส่ id ต่อท้าย:

```bash
python3 tools/gen_voice.py  episodes/ep01/script.json s03 s07   # อัดเสียงใหม่แค่ 2 ท่อน
python3 tools/gen_images.py episodes/ep01/shots.json  v04       # วาดภาพใหม่แค่ช็อตเดียว
```

### 🔒 พอเสียงผ่านแล้ว ให้ล็อกทันที

```bash
python3 tools/gen_voice.py episodes/ep01/script.json --approve
```

หลังจากนี้ **จะไม่มีการยิง TTS ให้ท่อนพวกนั้นอีกเลย** แม้จะแก้ข้อความในสคริปต์ไปแล้วก็ตาม
มีไว้สำหรับเคสที่เจอบ่อยที่สุด: *เสียงผ่านแล้วแต่คลิปยังไม่ผ่าน* พอสร้างคลิปใหม่ก็ใช้เสียงเดิมเสมอ
ถ้าจำเป็นต้องอัดใหม่จริงๆ ใช้ `--force` หรือลบ `audio/approved.json`

## รูปแบบไฟล์

**`script.json`**
```json
{
  "title": "ชื่อตอน",
  "voice": "Charon",
  "style": "อ่านด้วยความเร็วปกติแบบผู้บรรยายสารคดี เสียงต่ำ นิ่ง ชัดถ้อยชัดคำ ไม่ยืดเสียง",
  "rate": 1.0,
  "disclaimer": "ภาพประกอบทั้งหมดเป็นภาพจำลอง สร้างด้วย AI ไม่ใช่ภาพถ่ายเหตุการณ์จริง",
  "segments": [
    { "id": "s01", "text": "..." },
    { "id": "s02", "text": "...", "voice": "Kore", "rate": 1.05 }
  ]
}
```
- `rate` — จูนความเร็วเสียงเพิ่มเติมหลัง TTS (1.0 = ตามที่ได้มา, 1.1 = เร็วขึ้น 10%) ระดับเสียงไม่เพี้ยน
- `disclaimer` — ขึ้นเป็นแถบเล็กด้านบนจอ 6 วินาทีแรกของคลิป ใส่ไว้ทุกตอน (ดู "กติกาภาพ")

**`shots.json`**
```json
{
  "model": "gemini-3.1-flash-image",
  "aspect": "16:9",
  "style": "cinematic documentary still, no text or watermark",
  "shots": [
    { "id": "v01", "seg": "s01", "prompt": "..." },
    { "id": "v02", "seg": "s01", "prompt": "..." },
    { "id": "v03", "seg": ["s02", "s03"], "prompt": "..." }
  ]
}
```
`seg` บอกว่าช็อตนี้คลุม segment ไหน — ใช้ได้ทั้งสองทาง:
- **หลายช็อตชี้ segment เดียวกัน** (v01, v02 → s01) = แบ่งเวลาท่อนนั้นเท่าๆ กัน ภาพเปลี่ยนถี่ขึ้น
- **ช็อตเดียวคลุมหลาย segment** (v03 → s02+s03) = ภาพค้างยาวข้ามท่อน

### 📌 มาตรฐานความถี่ภาพ — ล็อกไว้แล้ว อย่าลดลง

ผ่านการตรวจจากคลิปพรีวิวแล้วว่า **"กำลังดี"** ใช้ตัวเลขชุดนี้เป็นมาตรฐานของทุกตอนต่อจากนี้:

| ตัวชี้วัด | ค่ามาตรฐาน |
|---|---|
| ภาพต่อ segment | **~2 ภาพ** |
| ภาพเปลี่ยนทุก | **8–9 วินาที** |
| อ้างอิงจริง | ep00: 40 ภาพ / 20 ท่อน / 5 นาที 44 วินาที |

`build_video.py` จะขึ้นเตือนให้เองว่าช็อตไหนค้างจอเกิน 12 วินาที (ปรับได้ที่ `MAX_SHOT`)
เจอเตือนเมื่อไหร่ = เพิ่มภาพให้ท่อนนั้น อย่าปล่อยผ่าน

## โครงเรื่องมาตรฐานของช่อง

ทุกตอนใช้โครงนี้ — คนดูต้องรู้ตั้งแต่ 10 วินาทีแรกว่า "ทำไมต้องดูต่อ"
แล้วต้องได้ **ที่มาและเหตุผล** ว่าทำไมเรื่องถึงเป็นแบบนั้น ไม่ใช่แค่เล่าว่าเกิดอะไรขึ้น

| ท่อน | หน้าที่ | สัดส่วน |
|---|---|---|
| **1. Hook** | เปิดด้วยประโยคที่ท้าให้คนไม่เชื่อ — "คุณจะเชื่อไหม ถ้าผมบอกว่า..." / "เคยได้ยินเรื่องที่..." แล้วโยนภาพที่แปลกที่สุดของเรื่องใส่เลย **ห้ามเริ่มด้วยวันที่หรือชื่อสถานที่** | ~10% |
| **2. ยืนยันว่าเรื่องจริง** | บอกทันทีว่ามีหลักฐานอะไร — เอกสารราชการ บันทึกร่วมสมัย งานวิจัย เพื่อตัดความรู้สึก "นี่มันนิทาน" ออกไป | ~5% |
| **3. ปมค้าง** | ทิ้งไว้ว่ามีอะไรที่แปลกกว่านั้นอีก แต่ยังไม่เฉลย ให้คนดูต้องรอ | ~5% |
| **4. ที่มา / บริบท** | ยุคนั้นเป็นยังไง เมืองนั้นเป็นยังไง คนตอนนั้นเชื่ออะไร — ท่อนนี้คือหัวใจ เพราะมันทำให้เรื่องประหลาด "มีเหตุผล" ขึ้นมา | ~20% |
| **5. เหตุการณ์** | เล่าตามลำดับเวลา ทีละขั้น ให้คนดูเห็นภาพว่ามันบานปลายยังไง | ~35% |
| **6. คำอธิบาย** | ทฤษฎีที่คนเชื่อกัน → ทฤษฎีนั้นมีจุดอ่อนตรงไหน → คำอธิบายที่ดีที่สุดตอนนี้คืออะไร | ~20% |
| **7. ปิดเรื่อง** | ย้ำสิ่งที่ยังไม่มีคำตอบ | ~5% |
| **8. Outro** | **ห้ามจบดื้อๆ เด็ดขาด** — ต้องมีครบสามอย่าง: (ก) ฝากความคิดถึงคนดู ว่าเรื่องนี้ทิ้งอะไรไว้ให้คิด (ข) ถามคำถามตรงๆ แล้วชวนคอมเมนต์ (ค) ทีเซอร์คลิปหน้าแบบเล่าปมสั้นๆ ให้อยากดู แล้วชวนกดติดตาม | ~12% |

**เรื่องน้ำเสียง:** เขียนเป็น **ภาษาพูดแบบคุยกับเพื่อน** ไม่ใช่ภาษาเขียนหรือภาษาข่าว
ใช้ "ผม" "เรา" "คุณ" ได้เต็มที่ แทรกความเห็นตัวเองบ้าง (`ผมว่าน่าขนลุกที่สุดคือ...`)
ถามคำถามกลางเรื่องบ้าง (`ฟังดูเข้าท่าใช่ไหมครับ`) และบอกตรงๆ เมื่อไม่รู้ (`ผมต้องบอกตรงๆ ว่าไม่มีใครรู้ครับ`)
`นะครับ` ใส่ได้แต่อย่าถี่จนน่ารำคาญ

**กฎเหล็ก:** ตัวเลขที่ไม่มีใครรู้แน่ ต้องพูดตรงๆ ว่าไม่มีใครรู้ — อย่าเดาให้ดูน่าตื่นเต้น
ความน่าเชื่อถือคือทุนของช่องแนวนี้ เสียครั้งเดียวคือจบ

ดูตัวอย่างที่ใช้โครงนี้จริงได้ที่ `episodes/ep00-demo-dancing-plague/script.json`

## เคล็ดลับเขียนสคริปต์ให้ TTS อ่านถูก

- **เขียนตัวเลขเป็นคำ** — `1518` อ่านผิดได้ ให้เขียน `หนึ่งห้าหนึ่งแปด` หรือ `ปี ค.ศ. 1518` (แบบหลังอ่านถูก)
- **ใส่ช่องว่างคั่นวลี** แทนการใช้จุลภาค — TTS ใช้ช่องว่างเป็นจังหวะหายใจ และ `captions.py` ก็ใช้ตัดบรรทัดซับด้วย
- **ชื่อต่างประเทศให้ทับศัพท์ไทย** — `Frau Troffea` → `ฟราว โทรฟเฟีย`
- **ท่อนละ 15–30 วินาที** — ยาวกว่านี้ซับจะซอยเยอะและแก้ยากเวลาอยากอัดใหม่

## เคล็ดลับเขียน prompt ภาพ

- บรรยาย **ฉาก แสง มุมกล้อง อารมณ์** ไม่ใช่แค่ชื่อสิ่งของ
- ปิดท้าย `style` ด้วย `no text, no watermark` เสมอ — โมเดลชอบแอบใส่ตัวหนังสือ
- **อย่าให้โมเดลเขียนภาษาไทยลงในภาพ** สะกดเพี้ยนแน่นอน ใส่ตัวหนังสือทีหลังด้วย `captions.py`
- อย่าขอให้วาดหน้าคนจริงที่ยังมีชีวิต

## กติกาภาพ (สำคัญ — อย่าข้าม)

ภาพในคลิปทุกใบเป็น **ภาพที่ AI สร้างขึ้นใหม่ ไม่ใช่ภาพถ่ายของเหตุการณ์จริง**
เพราะเครื่องนี้โหลดภาพจากอินเทอร์เน็ตไม่ได้ (เน็ตถูกบล็อก — ดู `CAPABILITIES.md`)

ดังนั้นทุกคลิปต้อง:
1. ขึ้นข้อความกำกับช่วงต้นคลิปว่า **"ภาพประกอบเป็นภาพจำลอง"** — ใส่ `"disclaimer"` ใน `script.json`
   แล้ว `build_video.py` จะขึ้นแถบนี้ให้อัตโนมัติ 6 วินาทีแรก
2. ใส่บรรทัดเดียวกันไว้ในคำอธิบายวิดีโอ พร้อมลิสต์แหล่งอ้างอิงของเนื้อหา
3. ไม่วาดภาพให้ดูเหมือนหลักฐานจริง (เอกสารราชการปลอม ภาพถ่ายที่เกิดเหตุปลอม)

ถ้าอยากใช้ภาพจริง ให้โหลดมาเองบนเครื่องคุณแล้ววางไว้ใน `episodes/<ตอน>/images/`
ตั้งชื่อไฟล์ตาม id ของช็อต (เช่น `v03.jpg`) — pipeline หยิบไปใช้ทันที ไม่ต้องแก้โค้ด
