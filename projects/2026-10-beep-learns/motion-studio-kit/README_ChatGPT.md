# ทดสอบ Motion Studio กับ ChatGPT

## วิธีทดสอบให้ยุติธรรม (ใช้หัวข้อเดียวกันทั้งสองฝั่ง)
1. สร้าง Project หรือ Custom GPT ใน ChatGPT แล้ววางเนื้อหา `SKILL.md` เป็น Instructions
2. แนบ `motion-studio-kit.zip` ไว้ในแชท
3. รอบที่ 1 (Brief): พิมพ์ "สร้างคลิป BEEP ไปออสเตรเลีย" แล้วดูว่าส่ง Brief ตามแบบฟอร์มหรือไม่ เช็คข้อเท็จจริงไหม และมุกตลกพอไหม
4. รอบที่ 2 (Build): พิมพ์ "ผ่าน สร้างได้เลย 16:9 ยาว 60 วิ"

## จุดที่ควรจับตา
- **รันได้ในแซนด์บ็อกซ์ของ ChatGPT ไหม:** ขั้นสร้างต้องใช้ Node, Chromium (Playwright), ffmpeg และดาวน์โหลดโมเดลเสียงจาก GitHub ถ้าแซนด์บ็อกซ์ไม่มีอินเทอร์เน็ตหรือไม่มี Chromium จะเรนเดอร์ไม่ได้ ให้สั่งว่า "ส่งไฟล์ story.js, episode.js, lines.txt, cast.json มา" แล้วนำมารันบนเครื่องตามขั้นตอนใน README_TH.md
- **โค้ดรันผ่านรอบแรกไหม:** นับจำนวน error ก่อนได้ภาพ
- **ใช้ตัวละครจาก kit จริงไหม:** หรือแอบวาดตัวละครใหม่เอง ซึ่งผิดกฎ
- **ตรวจงานเองไหม:** ดูว่าทำ critique loop จาก stills จริงหรือข้าม
