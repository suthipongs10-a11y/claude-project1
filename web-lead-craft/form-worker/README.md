# form-worker — ตัวรับฟอร์มของเว็บลูกค้าทุกเจ้า

เว็บที่เราทำเป็นไฟล์นิ่ง ๆ บน Cloudflare Pages ไม่มีเซิร์ฟเวอร์อยู่หลังบ้าน
**ฟอร์มติดต่อจึงไม่มีที่ให้ส่งไป** ตัวนี้คือที่ให้ส่ง — รับฟอร์มจากเว็บลูกค้า
แล้วยิงเข้า LINE Official Account ของลูกค้ารายนั้นทันที

**Worker ตัวเดียวใช้กับลูกค้าทุกเจ้า** เพิ่มลูกค้าใหม่ = แก้ secret ไม่ต้อง deploy ใหม่

```
เว็บลูกค้า (Cloudflare Pages)  →  Worker ตัวนี้  →  LINE OA ของลูกค้า
     ฟอร์ม + honeypot              เช็ก origin        ข้อความเข้ามือถือเจ้าของร้าน
                                   กรอง + จัดรูปแบบ
```

ไม่มีการเก็บข้อมูลไว้ที่ Worker เลย — ส่งต่อแล้วจบ ไม่มี KV ไม่มีฐานข้อมูล
ซึ่งเป็นสิ่งที่เขียนในหน้านโยบายความเป็นส่วนตัวได้ตรง ๆ

## ค่าใช้จ่าย

ฟรี Cloudflare Workers ให้ 100,000 request/วัน ฟอร์มร้านหนึ่งใช้ไม่ถึงร้อย

## Deploy ครั้งแรก (ทำครั้งเดียว)

```bash
cd web-lead-craft/form-worker
npx wrangler login                  # เปิดเบราว์เซอร์ให้ล็อกอิน Cloudflare
npx wrangler deploy                 # ได้ URL: https://wlc-form.<subdomain>.workers.dev
```

จำ URL ที่ได้ไว้ — ต้องเอาไปใส่ในเว็บลูกค้าทุกเว็บ

## เพิ่มลูกค้าใหม่ (ทำทุกครั้งที่รับงาน)

**1. ขอของจากลูกค้า** — สองอย่างนี้ลูกค้าต้องเป็นคนทำ เราทำแทนไม่ได้

| ต้องได้ | เอามาจากไหน |
|---|---|
| LINE Official Account | ลูกค้าสมัครเองที่ `manager.line.biz` ฟรี · **ใช้ LINE ส่วนตัวไม่ได้** |
| Channel Access Token | `developers.line.biz` → Messaging API → Issue token (long-lived) |
| userId หรือ groupId ปลายทาง | ดูวิธีหาข้างล่าง |

**หา `lineTo` ยังไง** — วิธีที่ง่ายที่สุดคือสร้างกลุ่ม LINE ของร้าน เชิญ OA เข้ากลุ่ม
แล้วอ่าน `groupId` จาก webhook event ตอนแรก (ตั้ง webhook ชั่วคราวที่ `webhook.site` ก็ได้)
ข้อดีของการส่งเข้ากลุ่มคือ **พนักงานหลายคนเห็นพร้อมกัน** ไม่ผูกกับมือถือเครื่องเดียว

**2. เพิ่มเข้า secret**

```bash
cp sites.example.json sites.json     # sites.json อยู่ใน .gitignore
# แก้ sites.json ใส่ origin จริงของลูกค้า + token + lineTo
npx wrangler secret put SITES < sites.json
```

> **key คือ origin ของเว็บ ตรงตัวที่เบราว์เซอร์ส่งมา** — `https://ชื่อโดเมน` ไม่มี `/` ปิดท้าย
> ถ้าเว็บเปิดได้ทั้ง `example.com` และ `www.example.com` ต้องใส่ **ทั้งสองอัน**
> origin ที่ไม่อยู่ในลิสต์จะโดนปฏิเสธ 403 — นั่นคือสิ่งที่กันคนอื่นมายืมฟอร์มเราส่งสแปม

**3. ชี้เว็บลูกค้ามาที่ Worker** — แก้ `src/head.html` ของเว็บนั้นบรรทัดเดียว

```js
w.FORM_ENDPOINT = 'https://wlc-form.<subdomain>.workers.dev/';
```

ปล่อยว่าง = ฟอร์มแค่ทำท่าส่ง (โหมดเดโม่) แล้ว build ใหม่ตามปกติ

**4. ทดสอบก่อนส่งมอบ** กรอกฟอร์มจริงบนเว็บที่ deploy แล้ว แล้วดูว่าข้อความเข้า LINE
ถ้าไม่เข้า เปิด `npx wrangler tail` ดู log สด ๆ ได้เลย

## กันสแปม

| ชั้น | ทำอะไร |
|---|---|
| origin allowlist | เว็บที่ไม่รู้จักยิงเข้ามาไม่ได้ |
| honeypot (`wlc_hp`) | ช่องที่คนมองไม่เห็น บอทกรอก = ทิ้งเงียบ ๆ ตอบ 200 ให้บอทคิดว่าสำเร็จ |
| timing | กรอกเสร็จเร็วกว่า 2.5 วินาที = ไม่ใช่คน ทิ้งเหมือนกัน |
| field allowlist | รับเฉพาะช่องที่เรารู้จัก ที่เหลือทิ้ง — ฟอร์มนี้ส่งต่ออะไรก็ได้ไม่ได้ |

ช่องที่ Worker รับ (นอกจากนี้ทิ้งทั้งหมด):
`name` `company` `tel` `email` `type` `pest` `size` `date` `slot` `note`
— ถ้าฟอร์มของเว็บใหม่ต้องใช้ชื่อช่องที่ไม่มีในลิสต์นี้ ต้องเพิ่มใน `LIMITS`
และ `LABELS` ใน `src/worker.mjs` ก่อน ไม่งั้นข้อมูลจะหายเงียบ ๆ

**ชื่อช่อง honeypot ห้ามเป็น `website` / `url` / `email2`** เพราะ autofill ของเบราว์เซอร์
อาจกรอกให้ลูกค้าจริงโดยที่เขาไม่รู้ตัว แล้วใบสั่งงานจริงจะหายเงียบทุกใบ

ถ้าวันไหนโดนสแปมหนักจริงจนสองชั้นนี้เอาไม่อยู่ ค่อยเพิ่ม Cloudflare Turnstile
(ฟรี) แต่มันจะเพิ่มสคริปต์ภายนอกและคุกกี้ ซึ่งต้องไปแก้หน้า PDPA ด้วย — อย่าใส่ก่อนจำเป็น

## เทสต์

```bash
node --test form-worker/test/worker.test.mjs      # กฎทั้งหมดของ Worker (20 เคส)
```

เทสต์ยิงเข้า handler ตัวจริงที่ deploy ไม่ใช่โค้ดจำลอง มีแต่ `api.line.me` ที่ถูกสตับ

ทดสอบทั้งสายตั้งแต่เบราว์เซอร์ (ต้องเปิดสามอย่างพร้อมกัน):

```bash
# 1. LINE ปลอม
node form-worker/test/fake-line.mjs 8788 /tmp/line-log.jsonl &

# 2. Worker ตัวจริงบน workerd
cd form-worker && npx wrangler dev --port 8787 --local \
  --var SITES:'{"http://127.0.0.1:4321":{"name":"ทดสอบ","lineToken":"t","lineTo":"U1","lineApi":"http://127.0.0.1:8788"}}' &

# 3. เบราว์เซอร์จริงกรอกฟอร์มจริง
node form-worker/test/e2e.mjs sites/demo-cleaning /index.html http://127.0.0.1:8787/ /tmp/line-log.jsonl
```

`lineApi` มีไว้ให้เทสต์ชี้ไป LINE ปลอมเท่านั้น ของจริงไม่ต้องใส่

## เมื่อส่งไม่สำเร็จ

Worker ตอบ 502 เว็บจะขึ้นกล่องแดงบอกลูกค้าว่าส่งไม่สำเร็จ พร้อมเบอร์โทรให้กดโทรแทน
**ห้ามแก้ให้ขึ้นว่าสำเร็จเมื่อส่งไม่ได้** — ใบสั่งงานที่หายเงียบคือลูกค้าที่เสียไปโดยร้านไม่มีทางรู้
