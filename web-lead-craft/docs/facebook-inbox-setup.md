# ตั้งค่าแชทอัตโนมัติของเพจ Facebook

ต้นฉบับเดียวของข้อความตอบอัตโนมัติ ถ้าแก้ข้อความ **แก้ที่ไฟล์นี้ก่อน** แล้วค่อยไป
วางใน Facebook — ไม่งั้นวันหนึ่งจะจำไม่ได้ว่าอันไหนคืออันจริง

> **นี่ไม่ใช่ฟีเจอร์ "AI agent" ของ Meta** มันคือ *ระบบอัตโนมัติแบบกฎ* (Automations)
> เราเขียนข้อความเองทุกตัวอักษร ซึ่งเป็นสิ่งที่ต้องการ เพราะเราขายของที่มีราคาตายตัว
> AI ที่เราคุมคำพูดไม่ได้อาจบอกราคาผิดหรือรับปากสิ่งที่เราไม่ได้ทำ (เช่น WordPress)
> ดูหัวข้อ "ถ้าเจอเมนู AI" ท้ายไฟล์

## ปัญหาที่กำลังแก้

จากโฆษณาชุดแรก: ทัก 7 คน หายไป 6 เวลาตอบครั้งแรกเฉลี่ย **4 ชั่วโมง 10 นาที**
คนที่ทักจากโฆษณาทักหลายเจ้าพร้อมกัน ใครตอบก่อนได้คุยก่อน

**เป้าหมายของแชทนี้ไม่ใช่ "คุยเก่ง" แต่คือเก็บ 3 อย่างให้ได้ก่อนเขาหาย**

1. ธุรกิจของเขาทำอะไร
2. เขาอยากได้อะไร
3. ช่องทางติดต่อ — และทิ้งเบอร์เราไว้ทุกกรณี

## กฎ 3 ข้อ

1. **ถามทีละข้อ** — ขอ "ชื่อ เบอร์ ธุรกิจ งบ" รวดเดียวคือแบบฟอร์ม คนหนี
2. **เรียงจากของถูกไปของแพง** — ธุรกิจ (หวงน้อย) → ความต้องการ → ลิงก์เพจ → เบอร์ (หวงมาก)
   ห้ามขอเบอร์ในข้อความแรก
3. **ทุกข้อความมีเบอร์กับ LINE ของเรา** — คนที่เงียบใน Messenger บางคนไปแอด LINE
   ทีหลัง แต่ต่อเมื่อเขามีไอดี

## ข้อความที่ 1 — ตอบกลับทันที (Instant reply)

```
สวัสดีครับ 🙏 Web Lead Craft ครับ
ขอบคุณที่ทักมานะครับ

ขอถามสั้น ๆ ข้อเดียวก่อน เพื่อจะได้ส่งตัวอย่างที่ตรงกับงานคุณจริง ๆ ครับ

👉 ธุรกิจของคุณทำเกี่ยวกับอะไรครับ?

พิมพ์คำเดียวมาก็ได้ครับ เช่น
• ร้านอาหาร   • คลินิก   • รับเหมา   • ขายออนไลน์   • บริการ

ตอบมาปุ๊บ ผมส่งตัวอย่างเว็บจริงให้ดูเลยครับ

━━━━━━━━━━
ถ้าสะดวกคุย LINE มากกว่า แอดได้เลยครับ: kitty4uu
โทร 099-151-4049
```

## ข้อความที่ 2 — คำหลัก (ทำ 5 ชุด)

คำหลัก: `ร้านอาหาร` `คลินิก` `รับเหมา` `ขายออนไลน์` `บริการ`
เปลี่ยนคำในวงเล็บและลิงก์เดโม่ให้ตรงกับแต่ละชุด

```
[ร้านอาหาร]ใช่ไหมครับ พอดีเลย 👍
ตัวอย่างเว็บที่ผมทำครับ ดูได้เลยไม่ต้องสมัครอะไร

🔗 [ลิงก์เดโม่]

แล้วตอนนี้ที่อยากได้คือแบบไหนครับ ตอบเป็นข้อก็ได้ครับ

1️⃣ ยังไม่มีเว็บเลย อยากมีหน้าร้านออนไลน์ให้ลูกค้าเห็นว่าเราน่าเชื่อถือ
2️⃣ มีเว็บอยู่แล้ว แต่เก่า / ช้า / แก้เองไม่ได้
3️⃣ อยากได้เว็บที่ลูกค้ากรอกฟอร์มแล้วเด้งเข้ามือถือเลย
4️⃣ ยังไม่แน่ใจ อยากฟังคำแนะนำก่อน
```

**ห้ามตัดข้อ 4 ออก** คนที่ไม่แน่ใจแล้วไม่มีข้อให้เลือกจะเงียบไปเลย

**อย่าใช้ `1` `2` `3` เป็นคำหลัก** มันจะไปแมตช์กับ "1,990" ใช้ชื่อธุรกิจเป็นคำหลักแทน
— คนพิมพ์ "ร้านอาหารครับ" ก็แมตช์ คนกดตามเมนูก็แมตช์

## ข้อความที่ 3 — ตรงนี้ถึงค่อยขอช่องทางติดต่อ

ส่งเอง หรือตั้งเป็นคำหลักจากคำว่า `ยังไม่มีเว็บ` `มีเว็บแล้ว` `ฟอร์ม` `ไม่แน่ใจ`

```
เข้าใจแล้วครับ 👌 แบบนี้ผมพอเห็นภาพแล้ว

ขอ 2 อย่างนี้หน่อยได้ไหมครับ เดี๋ยวผมทำ "ตัวอย่างหน้าเว็บ + ราคาแบบละเอียด"
ส่งให้ดูภายในวันนี้ ฟรี ไม่มีมัดจำครับ

1) ลิงก์เพจร้านคุณ (จะได้ดูรูป/บริการของจริง)
2) เบอร์โทร หรือ LINE ID

ที่ขอเบอร์เพราะพิมพ์คุยกันใน Messenger มันยาวครับ 😅
คุยเสียง 5 นาทีจบเลย แต่ถ้าไม่สะดวกให้เบอร์ก็ไม่เป็นไรครับ
แอด LINE ผมมาก็ได้: kitty4uu
```

ที่มันได้เบอร์เพราะ: บอกเหตุผลที่เป็นประโยชน์**กับเขา** ("พิมพ์ยาว คุยเสียง 5 นาทีจบ") ·
ให้**สองประตู** ให้เบอร์เรา หรือแอดเรา · "ไม่สะดวกก็ไม่เป็นไร" ลดแรงกดดัน

## ติดตามคนที่เงียบ

> **กฎ 24 ชั่วโมงของ Meta** — หลังลูกค้าพิมพ์หาเราครั้งสุดท้าย เราส่งข้อความหาเขาได้
> อีก 24 ชั่วโมงเท่านั้น เกินนั้นส่งไม่ได้ ยกเว้นใช้ message tag ที่ต้องขออนุมัติก่อน
> **แผน "ตาม 1 วัน แล้วตามอีก" ทำไม่ได้** ต้องอัดให้จบใน 24 ชั่วโมง

**+1 ชั่วโมง ไม่ตอบ**

```
เผื่อไม่สะดวกพิมพ์ตอนนี้นะครับ 🙂
ผมทิ้งตัวอย่างเว็บจริงไว้ให้ดูก่อนเลยครับ ไม่ต้องตอบก็ได้
🔗 [ลิงก์]
```

**+20 ชั่วโมง ยังไม่ตอบ — ข้อความสุดท้าย และสำคัญที่สุด**

```
สวัสดีครับ ผมขอทิ้งช่องทางไว้ให้นะครับ
เผื่อวันหลังอยากได้ข้อมูลเพิ่ม ทักมาได้ตลอดไม่ต้องเกรงใจครับ

📞 099-151-4049
💬 LINE: kitty4uu
🌐 shopdashth.com

ตอนนี้ยังไม่พร้อมก็ไม่เป็นไรเลยครับ เก็บเบอร์ไว้ก่อนได้ 🙏
```

คนที่เงียบวันนี้ไม่ได้แปลว่าไม่เอา หลายคนกลับมาอีก 2 เดือน —
**แต่กลับมาได้เฉพาะคนที่มีเบอร์เราเก็บไว้**

## ข้อความเมื่อไม่อยู่ (Away message)

ใช้ข้อความที่ 1 แล้วเติมบรรทัดบนสุด:

```
ตอนนี้นอกเวลาทำการครับ ผมตอบเช้าพรุ่งนี้ 9 โมงครับ
ถ้าด่วน โทร 099-151-4049 ได้เลยครับ
```

## คำถามที่พบบ่อย (ตั้ง 3 ข้อ)

ขึ้นเป็นปุ่มให้กด ได้ข้อมูลฟรีว่าเขาสนใจอะไรโดยไม่ต้องถาม

| คำถาม | คำตอบ |
|---|---|
| ราคาเท่าไหร่ | 3 แพ็กเกจครับ **990** หน้าเดียวจบ · **1,990** หน้าเดียว 2 ภาษา + ฟอร์มเด้งเข้ามือถือ · **5,990** หลายหน้า + บทความ + แก้เนื้อหาเองได้ ทุกแพ็กเกจรวมโดเมนปีแรกและหน้านโยบายความเป็นส่วนตัว (PDPA) ครับ |
| ใช้เวลากี่วัน | 990 กับ 1,990 ประมาณ 3-5 วันหลังได้ข้อมูลครบครับ · 5,990 ประมาณ 7-10 วัน ช้าสุดคือรอเนื้อหากับรูปจากลูกค้าครับ 😅 |
| ขอดูตัวอย่างงาน | ได้เลยครับ 🔗 [ลิงก์] ดูในมือถือได้เลย ทุกเว็บโหลดเร็วและใช้บนมือถือได้เต็มจอครับ |

## เข้าไปตั้งตรงไหน

**คอมพิวเตอร์ (แนะนำ ตั้งง่ายกว่าเยอะ)**

```
business.facebook.com  →  เลือกเพจให้ถูก (มุมซ้ายบน)
   →  กล่องข้อความ (Inbox)
   →  ระบบอัตโนมัติ (Automations)   ← ทุกอย่างอยู่ในนี้
```

**มือถือ** — แอป Meta Business Suite → กล่องข้อความ → ไอคอนฟันเฟือง → ระบบอัตโนมัติ

> ชื่อเมนูอาจเพี้ยนไปบ้างตามเวอร์ชัน Meta เปลี่ยนชื่อบ่อยมาก
> ให้มองหาคำว่า **"ระบบอัตโนมัติ" / "Automations"** เป็นหลัก

| ตั้งตรงไหน | ใส่อะไร |
|---|---|
| ตอบกลับทันที (Instant reply) | ข้อความที่ 1 |
| ระบบอัตโนมัติ → สร้างใหม่ → คำหลัก | ข้อความที่ 2 × 5 ชุด |
| ระบบอัตโนมัติ → ขอข้อมูลติดต่อ | เปิด — ดูหมายเหตุข้างล่าง |
| คำถามที่พบบ่อย | 3 ข้อในตาราง |
| ข้อความเมื่อไม่อยู่ | ข้อความที่ 1 + บรรทัดนอกเวลา |

**"ขอข้อมูลติดต่อ" (Request contact info) คุ้มที่สุดถ้าบัญชีมี** — มันส่งการ์ดให้ลูกค้า
**กดปุ่มเดียว**เพื่อแชร์เบอร์/อีเมลที่ Facebook มีอยู่แล้ว ไม่ต้องพิมพ์เอง
แรงเสียดทานหายไปเกือบหมด ตั้งให้ยิงหลังข้อความที่ 2 ไม่ใช่ก่อน

## ทดสอบก่อนปล่อย — ห้ามข้าม

ทดสอบด้วยบัญชี Facebook ของตัวเองไม่ได้ ระบบจะไม่ยิงให้แอดมินเพจ

1. ยืมมือถือคนอื่น หรือใช้บัญชีที่ไม่ใช่แอดมินเพจ
2. ทักเข้าเพจว่า "สนใจครับ" → ต้องเด้งข้อความที่ 1 ทันที
3. ตอบว่า "ร้านอาหารครับ" → ต้องเด้งข้อความที่ 2
4. กดปุ่มคำถามที่พบบ่อยทั้ง 3 ปุ่ม → ตรวจว่าลิงก์เปิดได้จริงและราคาถูกต้อง
5. ลบแชทนั้นทิ้ง ไม่งั้นสถิติของเพจจะเพี้ยน

**เช็กเรื่องลิงก์ให้ดี** ลิงก์ที่พิมพ์ผิดคือลูกค้าที่หายโดยเราไม่มีทางรู้

## ถ้าเจอเมนู "AI" / "AI agent" / "ผู้ช่วย AI ทางธุรกิจ"

Meta ทยอยเปิดฟีเจอร์ AI ตอบแชทให้บางบัญชี ถ้าเห็นในเมนูแปลว่าบัญชีคุณได้แล้ว
มันต่างจากที่เราตั้งข้างบนอย่างนี้:

| | ระบบอัตโนมัติ (ที่เราทำ) | AI ของ Meta |
|---|---|---|
| ใครเขียนคำตอบ | เราเขียนเองทุกตัวอักษร | AI แต่งเอาเองจากข้อมูลเพจ |
| ตอบคำถามนอกสคริปต์ | ไม่ได้ | ได้ |
| คุมราคาที่มันพูดได้ไหม | **ได้ 100%** | **ไม่ได้** |
| ไล่ขอเบอร์ตามที่เราวางไว้ | ได้ | ไม่แน่นอน |

**ตั้งระบบอัตโนมัติให้เสร็จก่อนเสมอ** เพราะเราขายของที่มีราคาตายตัว AI ที่คุมคำพูด
ไม่ได้อาจบอกราคาผิด หรือรับปากสิ่งที่เราไม่ทำ (WordPress, รับดูแลรายเดือนฟรี ฯลฯ)
ซึ่งกลายเป็นข้อผูกพันกับลูกค้าไปแล้ว

จะเปิด AI ก็ได้ แต่เปิดเป็น **ตัวสำรองสำหรับข้อความที่ไม่แมตช์คำหลัก** และก่อนเปิด
ให้ทดสอบด้วยการถามมันตรง ๆ ว่า *"ราคาเท่าไหร่"* / *"ทำ WordPress ไหม"* /
*"ลดราคาได้ไหม"* — ถ้าตอบผิดแม้ข้อเดียว ปิดทิ้ง

## ของถัดไป

  **ติดที่ต้องขอสิทธิ์ `pages_messaging` จาก Meta (App Review + ยืนยันธุรกิจ 1-3 สัปดาห์)**
- **หน้าฟอร์มคัดกรองบน shopdashth.com** — คนที่ยังไม่ให้เบอร์ ส่งลิงก์ให้กรอก 4 ช่อง
  แล้วเด้งเข้า LINE ผ่าน `form-worker/` ที่เขียนและเทสต์เสร็จแล้ว
