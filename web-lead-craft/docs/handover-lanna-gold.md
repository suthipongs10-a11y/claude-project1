## ⚠️ ก่อนเปิดใช้จริง — ลำดับสำคัญ

1. **ได้โดเมนจริงของเว็บ** แล้วใส่ใน `site.json` → `domain` (ตอนนี้ยังเป็น example.pages.dev)
2. **อัปโหลดโค้ด Worker ใหม่** (`form-worker/src/worker.mjs`) ขึ้น Cloudflare
   ตัวนี้รับ `entries` และไฟล์รูปได้ ตัวเก่ารับแค่ PDF
   - เว็บ SPM ใช้ Worker ตัวเดียวกัน แต่เทสต์ 58 เคสผ่านรวมของ SPM ด้วย พฤติกรรมของ SPM ไม่เปลี่ยน
3. **เพิ่ม entry ของเว็บนี้ใน SITES** (secret ของ Worker) เป็นการ*เพิ่ม* ไม่ใช่แทนของเดิม:
   ```json
   "https://<โดเมนจริง>": {
     "name": "Lanna East to Mekong 1200",
     "emailTo": ["kaewpuabike@gmail.com"],
     "emailFrom": "Lanna 1200 Registration <spm@shopdashth.com>",
     "forms": { "register": { "label": "ใบสมัคร", "attach": ["image", "pdf"], "entries": true } }
   }
   ```
4. Deploy เว็บ แล้ว**สมัครทดสอบหนึ่งใบพร้อมสลิป** และให้ผู้จัดยืนยันว่าได้อีเมล

ถ้าทำข้อ 4 ก่อนข้อ 2–3 ใบสมัครจะ**ไม่หายเงียบ** แต่จะขึ้นกล่องแดงว่าส่งไม่สำเร็จ พร้อมเบอร์ผู้จัด
