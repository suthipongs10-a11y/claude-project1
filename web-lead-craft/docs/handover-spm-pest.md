## ทำไมไม่มีรูปถ่ายสักรูป

ตั้งใจ สามเหตุผล:

1. **ยังไม่มีรูปจริงจากลูกค้า** และรูปสต็อกฝรั่งใส่ชุดขาวถือถังพ่นจะทำลาย
   ความน่าเชื่อถือของบริษัทที่ทำมา 30 ปีมากกว่าช่วย
2. **รูปแมลงไล่คนซื้อ** ผู้จัดการโรงแรมที่กำลังอ่านอยู่หน้าจอไม่อยากเห็นรูป
   แมลงสาบ ไอคอนลายเส้นขายได้ดีกว่า
3. **ไม่ต้องรอ** เว็บนี้ส่งให้ลูกค้าดูได้วันนี้ ไม่ต้องรอนัดถ่ายรูป

ถ้าลูกค้าส่งรูปมาแล้ว ค่อยเติมทีหลังได้ทันที — ระบบรูป (`src/img/*.webp` →
`{{img:name:sizes}}`) พร้อมอยู่แล้ว จุดที่ควรใส่รูปก่อนคือ ฮีโร่ (ทีมงาน/รถบริการ)
และแถบมาตรฐาน (เอกสาร/ใบอนุญาต)

## ข้อมูลที่ต้องขอจากลูกค้า

**ตอนนี้ (ยังไม่ตกลง) — ขอ 4 ข้อพอ** ที่เหลือเดาไว้ให้แล้ว

1. ชื่อบริษัทภาษาไทยที่ถูกต้อง (ตอนนี้เขียนว่า "ไซเอ็นทิฟิค เพสท์ แมเนจเม้นท์")
2. เบอร์โทร / LINE / อีเมล ที่จะรับงานจริง และ **ใครเป็นคนรับ**
3. ไฟล์โลโก้ (ตอนนี้วาดผีเสื้อขึ้นมาใหม่จากโลโก้ในรูปที่ส่งมา)
4. มีใบอนุญาตและออกรายงานหลังบริการให้ลูกค้าจริงไหม — **ข้อนี้สำคัญที่สุด**
   ทั้งหน้าเขียนบนสมมติฐานนี้ ถ้าไม่มีต้องรื้อแถบมาตรฐานใหม่

**หลังตกลง — ขอเพิ่ม**

- ที่อยู่สำนักงานใหญ่ + ที่อยู่/เบอร์ 4 สาขา
- สำเนาใบอนุญาต (ถ่ายรูปได้) — เอาขึ้นแถบมาตรฐาน
- มีประกันภัยความเสียหายไหม วงเงินเท่าไหร่ (ผู้จัดการโรงแรมถามทุกราย)
- เงื่อนไขรับประกันงานปลวกจริง — FAQ ตอนนี้เขียนกลาง ๆ ว่า "ระบุในใบเสนอราคา"
- ตัวอย่างรายงานหลังบริการ (ปิดชื่อลูกค้า) — เอามาแทนภาพจำลองในหน้า
- จำนวนลูกค้าที่ดูแลอยู่ แยกตามประเภท เช่น "โรงแรม 12 แห่ง"
- รูปถ่าย 8 รูป: รถบริการ / ทีมงานในเครื่องแบบ / ช่างกำลังทำงาน / อุปกรณ์ /
  สถานีเหยื่อที่ติดตั้งแล้ว / เอกสารรายงาน / ใบอนุญาตติดผนัง / หน้าออฟฟิศ
  — ถ่ายกลางวัน ถ่ายแนวนอน และ **ส่งมาแบบ "ไฟล์" ไม่ใช่ "รูปภาพ"** (LINE บีบอัดจนพัง)
  — ห้ามถ่ายติดชื่อโรงแรม/ป้ายลูกค้าโดยไม่ขออนุญาต ผิดสัญญารักษาความลับและ PDPA

## ฟอร์มรับงาน

ช่องที่เก็บ: `name` `company` `tel`(บังคับ) `type` `pest` `size` `date` `note`
พร้อม honeypot `wlc_hp`

**`company` กับ `pest` เป็นช่องใหม่** เพิ่มเข้า `form-worker/src/worker.mjs`
(`LIMITS` + `LABELS`) แล้วในรอบนี้ พร้อมเทสต์ — งาน B2B ที่ไม่รู้ว่าโทรมาจาก
ที่ไหนและเจอตัวอะไร คือใบงานที่โทรกลับไม่ได้

ตอนนี้ `FORM_ENDPOINT` ว่างอยู่ = โหมดเดโม่ กดส่งแล้วขึ้นสำเร็จแต่ไม่ส่งจริง
ก่อนขึ้นจริงต้อง deploy Worker แล้วใส่ URL ใน `src/head.html` และเพิ่ม origin
ของเว็บนี้เข้า SITES secret
