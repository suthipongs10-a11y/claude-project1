# ข้อมูลที่ต้องขอจากลูกค้า — เช็กลิสต์รับงาน

ใช้ได้กับงานทุกราย ตัวอย่างในวงเล็บอ้างงาน SPM Thailand (`sites/spm-pest`)

> **อย่าส่งทั้งไฟล์นี้ให้ลูกค้า** ลูกค้าที่เปิดมาเจอ 60 ข้อจะปิดทิ้ง
> ส่งเฉพาะ **ชุด A** ก่อน (8 ข้อ) ที่เหลือค่อยทยอยถามระหว่างทำงาน

## ชุด A — ไม่มีข้อไหนก็เริ่มงานไม่ได้

| # | ขอ | ถ้าไม่ได้จะเกิดอะไร |
|---|---|---|
| A1 | **ชื่อบริษัทเต็ม ไทย + อังกฤษ ตามหนังสือรับรอง** | ชื่อผิดตัวเดียวมีปัญหาตอนออกเอกสารและตอนจดทะเบียนใน Google |
| A2 | **ชื่อโดเมนเต็ม** + ผู้ให้บริการโดเมน/โฮสติ้ง + คนถือรหัส | เว็บขึ้นไม่ได้ · ดู §โดเมน ด้านล่าง |
| A3 | **โดเมนนี้ใช้กับอีเมลบริษัทด้วยไหม** | ข้อที่อันตรายที่สุดในลิสต์ · ดู §โดเมน |
| A4 | **เบอร์โทรที่จะให้ลูกค้าโทรเข้า** (เบอร์ออฟฟิศ + มือถือถ้ามี) | ปุ่มโทรทั้งเว็บใช้เบอร์นี้ |

## ชุด B — ข้อเท็จจริงที่เราเขียนไว้ก่อน ต้องให้เขายืนยัน

**อ่านข้อนี้ให้ดี** เราเขียนเนื้อหาให้ลูกค้าเพื่อลดภาระเขา แปลว่าเว็บกำลังพูดแทนเขา
ทุกประโยคที่เป็นคำสัญญาต้องได้รับการยืนยัน ไม่งั้นลูกค้าปลายทางเอาไปอ้างแล้วเขาเดือดร้อน

| ตอนนี้เว็บเขียนว่า | ต้องยืนยันว่า |
|---|---|
| ก่อตั้ง พ.ศ. 2537 / ประสบการณ์ 30 ปี | ปีที่ก่อตั้งจริง |
| มีใบอนุญาตถูกต้องตามกฎหมาย | มีจริงไหม เลขที่อะไร หมดอายุเมื่อไหร่ |
| มีผู้ควบคุมการใช้วัตถุอันตรายประจำบริษัท | มีจริงไหม |
| ออกรายงานหลังบริการทุกครั้ง | ทำจริงทุกครั้งไหม ขอตัวอย่าง 1 ใบ |
| มีผังจุดติดตั้งที่มีหมายเลขกำกับ | ทำจริงไหม |
| ทีมงานประจำ ไม่ใช่รับเหมาช่วง | จริงไหม (ถ้าใช้ซับบางงาน ต้องแก้ประโยค) |
| ทีมงานใส่เครื่องแบบ | จริงไหม |
| **สัญญารายปี เรียกเข้าเสริมได้ไม่จำกัด ไม่คิดเงินเพิ่ม** | ← คำสัญญาที่แรงที่สุดในเว็บ ต้องยืนยัน |
| งานปลวกมีรับประกัน | มีจริงไหม กี่ปี เงื่อนไขอะไร |
| เข้าบริการนอกเวลาทำการได้ | ทำได้จริงไหม คิดเพิ่มไหม |
| เวลาทำการ จันทร์–เสาร์ 8:00–17:00 | ตรงไหม มีสายด่วนนอกเวลาไหม |
| ให้บริการ 5 พื้นที่ (กรุงเทพฯ พัทยา ภูเก็ต สมุย หัวหิน) | ครบไหม มีที่อื่นอีกไหม |
| ดูแล 6 กลุ่มแมลง | ครบไหม มีบริการอื่นอีกไหม เช่น อบไม้ กำจัดนก |

## ชุด C — เนื้อหาแต่ละส่วน

**บริการแต่ละชนิด** (ปลวก หนู แมลงสาบ มด ยุง แมลงบิน)
- วิธีที่ใช้จริงของแต่ละชนิด — เราเขียนตามมาตรฐานอุตสาหกรรมไว้ก่อน เขาอาจทำต่างออกไป
- ชนิดไหนเป็นงานหลักที่รับมากที่สุด (เอาขึ้นก่อน)

**เครื่องดักแมลง**
- รุ่น/ยี่ห้อที่มี · ขายขาดราคาประมาณเท่าไหร่ · ค่าเช่ารายเดือนเท่าไหร่
- รอบเปลี่ยนหลอด/แผ่นกาว ทุกกี่เดือน

**กลุ่มลูกค้า** (โรงแรม / ร้านอาหาร / คอนโด / โรงงาน)
- ครบไหม กลุ่มไหนเยอะที่สุด · **จำนวนแต่ละกลุ่ม** เช่น "โรงแรม 12 แห่ง" ← ตัวเลขนี้ขายดีมาก

**สาขา 4 แห่ง** — ที่อยู่และเบอร์ของแต่ละสาขา หรือใช้เบอร์กลางเบอร์เดียว

**ขั้นตอนการทำงาน 4 ขั้น** (สำรวจ → เสนอราคา → เข้าบริการ → รายงาน) ตรงกับของจริงไหม

## ชุด D — เอกสารที่เอาขึ้นเว็บได้ (นี่คือของที่ขายจริง)

งาน B2B ขายด้วยเอกสาร ไม่ได้ขายด้วยรูปสวย

- [ ] **สำเนาใบอนุญาต** ถ่ายรูปมาก็ได้ — ขึ้นหน้าเว็บได้เลย
- [ ] **ตัวอย่างรายงานหลังบริการ** ปิดชื่อลูกค้าออก — แทนภาพจำลองที่เราวาดไว้
- [ ] **มีประกันภัยความเสียหายไหม วงเงินเท่าไหร่** ← ผู้จัดการโรงแรมถามทุกราย
- [ ] จำนวนลูกค้าที่ดูแลอยู่ แยกตามประเภท
- [ ] มีลูกค้าที่ยอมให้เอ่ยชื่อไหม — **ต้องขออนุญาตเป็นลายลักษณ์อักษรก่อน**
- [ ] จำนวนทีมช่าง / จำนวนรถบริการ
- [ ] สารเคมีที่ใช้ ขึ้นทะเบียน อย. ไหม ปลอดภัยกับพื้นที่อาหารไหม

## ชุด E — รูปถ่าย

ถ่ายด้วยมือถือได้หมด **ไม่ต้องจ้างช่างภาพ** — รูปจริงชนะรูปสต็อกเสมอในงานแบบนี้

1. รถบริการที่มีชื่อบริษัทข้างรถ
2. ทีมงานใส่เครื่องแบบยืนรวมกัน
3. ช่างกำลังทำงานจริง (ถ่ายด้านหลัง ไม่ต้องเห็นหน้า)
4. อุปกรณ์/เครื่องพ่นวางเรียง
5. สถานีเหยื่อหนูหรือกล่องดักที่ติดตั้งแล้ว
6. เอกสารรายงานหลังบริการ (ปิดชื่อลูกค้า)
7. ใบอนุญาตที่กรอบติดผนัง
8. หน้าออฟฟิศ/ป้ายบริษัท

**บอกเขา 3 ข้อนี้ทุกครั้ง**
- ถ่ายกลางวัน แสงธรรมชาติ
- **ถ่ายแนวนอน**
- **ส่งมาแบบ “ไฟล์” ไม่ใช่ “รูปภาพ”** — LINE บีบอัดจนพัง ถ้าส่งผิดวิธีได้รูปแตกมาใช้ไม่ได้

⚠️ **ห้ามถ่ายติดชื่อโรงแรมหรือป้ายลูกค้าโดยไม่ขออนุญาต** ผิดสัญญารักษาความลับที่เขาเซ็นไว้
กับลูกค้า และผิด PDPA ด้วย — เตือนข้อนี้ไปด้วยจะดูมืออาชีพมาก

## ชุด F — บัญชีและ SEO

- เพจ Facebook เดิม (ลิงก์)
- Instagram / TikTok ถ้ามี

- ต้องการติด Google Analytics ไหม (ถ้าเอา เราตั้งให้ ต้องมีบัญชี Google ของบริษัท)

## ชุด G — บอกเขาด้วยว่า “อะไรที่เราเขียนให้”

**ลดภาระเขา = งานได้เสร็จ** งานเว็บเล็ก ๆ ตายเพราะเนื้อหาไม่มา ไม่ใช่เพราะทำไม่เป็น

บอกไปเลยว่าเราร่างให้: ข้อความแนะนำบริษัท · คำอธิบายบริการแต่ละตัว · คำถามที่พบบ่อย ·
ข้อความบนปุ่มทุกปุ่ม · หน้านโยบายความเป็นส่วนตัว

**เขาแค่ต้องให้ข้อเท็จจริง ไม่ต้องเขียนหนังสือ**

## §โดเมน — จุดที่พังแล้วพังหนัก

บริษัทเก่าที่มีโดเมนอยู่แล้ว มักมีอีเมลบริษัทผูกกับโดเมนนั้นด้วย

**ถามให้ได้ก่อนแตะอะไรทั้งนั้น:**
1. ชื่อโดเมนเต็ม ๆ ว่าอะไร (อย่าเชื่อชื่อย่อที่เขาพูด — ขอใบแจ้งหนี้ค่าต่ออายุมาดูดีที่สุด)
2. ซื้อไว้กับใคร ใครเป็นคนถือรหัส
3. **ใช้กับอีเมลบริษัทอยู่ด้วยไหม** (`ชื่อ@โดเมนบริษัท`)

**ถ้าใช้กับอีเมลอยู่** → แก้เฉพาะเรคคอร์ดของเว็บ (A / CNAME) **ห้ามแตะ MX
ห้ามย้าย nameserver ทั้งก้อน ห้ามแนะนำให้ยกเลิกโฮสเดิม**
โฮสติ้งไทยมักแถมอีเมลมาในแพ็กเกจเดียวกัน ยกเลิกโฮส = อีเมลบริษัทดับ

**ถ้าไม่ได้ใช้กับอีเมล** → ยกเลิกโฮสเดิมได้ ประหยัดให้เขาปีละหลายพัน เป็นของแถมที่ดี

บอกตั้งแต่แรกว่า **“ถ้าไม่ได้ข้อมูลครบภายใน 7 วัน เราขึ้นโครงด้วยข้อความชั่วคราวไปก่อน
แล้วแก้ทีหลังได้”** — ลูกค้าจะได้ไม่รู้สึกว่าต้องรอให้ครบถึงจะเริ่ม และงานไม่ค้างที่เรา
